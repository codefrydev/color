# Color — Live Accessible Design System Studio

Developed by [codefrydev](https://codefrydev.in).

An advanced, mathematical design system and color palette generator engineered for modern web and native application stacks. Generate perceptually balanced 50–950 tonal scales with OKLCH curves, APCA/WCAG contrast ratings, and instant multi-format token compilation.

## Features

- **Perceptual Color Science**: OKLCH lightness calibration preventing mid-tone muddying and perceived luminance distortion.
- **Accessible Design Systems**: Automatic WCAG 2.2 and APCA contrast verification with live color-blindness simulation (Machado 2009).
- **Interactive Workbench**: Sticky sidebar rail with 360° polar color wheel, precision sliders, harmonic solvers (Analogous, Complementary, Triadic, Split-Comp, Tetradic, Square, Monochrome), and live drift.
- **Dedicated Real-World Preview Canvas**: Full-page dedicated preview studio with independent scrolling for SaaS Dashboards, E-Commerce Stores, Developer Documentation, Landing Pages, and Mobile App Shells.
- **Multi-Format Compilers**: Export straight to CSS custom properties, Tailwind CSS v4 `@theme`, Tailwind v3 config, Shadcn/UI tokens, W3C DTCG `tokens.json`, SwiftUI, and Jetpack Compose.
- **Static Export & GitHub Pages**: Pre-rendered static architecture deployed seamlessly to GitHub Pages.

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Production static export build
npm run build

# Deploy to gh-pages branch
npm run deploy
```
